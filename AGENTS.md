\#\# Document Version Management

The project maintains its documentation and agent skills in Google Drive.

The document version management instructions are located at:

\`.agents/skills/document-version-management/SKILL.md\`

Whenever the user explicitly approves a new documentary version:

1\. Read and follow the instructions in the referenced SKILL.md.  
2\. Identify previous versions of the approved document.  
3\. Move older versions into the corresponding \`@old\` directory.  
4\. Perform all file operations directly on the Google Drive project files.  
5\. Never create local copies as an alternative to modifying the original files.
